# Synthetic durability probe

This separate, read-only probe is prepared locally; it has not run on Railway. It is designed for the retained synthetic database created by the October 29 self-test. It requires synthetic-only configuration and the exact private-child path. A bounded supervisor runs the probe for at most 25 seconds, strips credential variables, suppresses child output and emits only fixed pass/stop categories.

The probe checks the mount and service ownership, root and child permissions, POSIX ACL xattrs, the fixed database's ownership, regular-file type, link count, size and private mode. It refuses existing or unreadable SQLite WAL, SHM and rollback-journal companions. It opens SQLite with `mode=ro&immutable=1`, checks integrity and aggregate synthetic flags, and requires exactly one synthetic sample, two batches and no gateway-status rows, the state created by the self-test. It does not query or print record values. Unexpected schema, counts, non-synthetic data or unknown filesystem metadata stop the probe.

These checks do not prove absence of non-POSIX ACLs, protect against same-UID or privileged path replacement, prove storage encryption or backup, or validate phone uploads, real health data, public HTTPS or unattended operation. SQLite later reopens the database by pathname, so concurrent replacement remains a limitation. A passing run would confirm only that this particular synthetic database is readable after stopping and restarting compute, not general durability across infrastructure failure.

Local verification: six tests initially passed using workspace synthetic SQLite fixtures. Following additional gateway-status checking and a query refactor, five in-memory/mock checks passed on the final code; the final revision has not been rerun against an on-disk SQLite fixture or on Linux/Railway. An earlier temporary-directory attempt failed at SQLite open with an unspecified `OperationalError`; automatic cleanup then explicitly returned Windows access denied on the system temporary directories. Those denied paths were not retried or removed.
